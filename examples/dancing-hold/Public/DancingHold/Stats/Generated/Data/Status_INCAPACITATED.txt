// Dancing Hold — Hold Person's mechanics, Otto's Irresistible Dance animation,
// Hold Person's visual effect.
//
// `using "HOLD_PERSON"` inherits the entire incapacitation package: the
// INCAPACITATED status type, the boosts (auto-failed Strength and Dexterity
// saves, attackers auto-crit within 3m, advantage against the target, movement
// blocked), the SG_Condition / SG_Incapacitated / SG_Paralyzed groups, the
// Wisdom saving throw that ends it, and StatusEffect 16afeddb — the Hold Person
// visual we wanted to keep.
//
// Three overrides do the whole job.
//
// The animation is the non-obvious part. Hold Person freezes the target through
// AnimationLoop and AnimationEnd, both pointing at a specific GR2
// (REAC_Magic_External_Combat_01). Otto's Irresistible Dance does not use those
// fields at all — it sets StillAnimationType to "Dancing", a named animation
// state. So the dance cannot be copied by copying an animation reference: there
// is none. You switch mechanisms, and clear the inherited freeze so the two do
// not compete.
//
// StillAnimationPriority is already "Snared" on both, so it needs no change.
new entry "HOLD_PERSON_DANCING"
type "StatusData"
data "StatusType" "INCAPACITATED"
using "HOLD_PERSON"
data "StillAnimationType" "Dancing"
data "AnimationLoop" ""
data "AnimationEnd" ""
data "DisplayName" "hc1562106g41a1g4ddagb857gea20ecca7ef9"
data "Description" "hb9d22a89gf498g4041gb7f3g85340491b4c0"
data "Icon" "Spell_OttosIrresistibleDance"
